# 🖥️ Computer Hardware Hunt

Play this game:


[👉👉👉Play👈👈👈](https://tharushadils.github.io/Introduction_to_Computers_-Simple_Game/)


**Computer Hardware Hunt** is a fun, colorful, and highly interactive educational browser mini-game designed for Grade 5 students (ages 10–11). It teaches primary students how to identify essential computer hardware components and understand their functions through an engaging 4-level quest.

---

## 🎯 Educational Objectives

The game helps students recognize and learn the core functions of key computer hardware:
* **Monitor:** Displays pictures, text, and videos.
* **Keyboard:** Used to type letters, numbers, and symbols.
* **Mouse:** Helps point, click, and select items on screen.
* **CPU / System Unit:** Processes instructions and runs the computer.
* **Printer:** Produces a physical paper copy of digital information.
* **Speakers:** Plays sound, voice, and music.
* **Webcam:** Captures video and photos.
* **Headphones:** Allows private audio listening.

---

## 🎮 Game Levels & Mechanics

1. **Level 1 – Lab Hunt 🔎**
   * Students explore a cartoon computer laboratory scene and click the requested target component among various objects and distractors.
2. **Level 2 – Hardware Match 🧩**
   * A drag-and-drop game where players match hardware illustrations to their correct name badges.
3. **Level 3 – Build the Computer 🛠️**
   * Students assemble an empty workstation desk by dragging monitor, CPU, keyboard, mouse, and speaker parts into designated slots.
4. **Final Challenge – Hardware Master ⚡**
   * A fast-paced, 10-second timed quiz testing knowledge of what each component is used for.
5. **Final Score Screen 🏆**
   * Displays total score, stars earned, time taken, accuracy percentage, and awards a rank badge (*Hardware Master*, *Hardware Explorer*, *Hardware Learner*, or *Keep Practicing*).

## ✨ Features

* **No External Dependencies / Frameworks:** Pure HTML5, CSS3 (Tailwind CSS via CDN), and Vanilla JavaScript.
* **Web Audio Synthesis:** Sound effects generated on the fly via the Web Audio API—no external audio files needed!
* **Particle Canvas Confetti:** Vibrant celebration animations upon completing levels.
* **Responsive UI:** Tailored for tablet touchscreens and desktop screens with large click targets and rounded child-friendly cards.
* **Animated Mascot ("Chip"):** Custom inline SVG computer character with fun floating animations.

---

## 🚀 How to Play

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
3. Click **▶ START GAME** to begin your hardware hunt!

## 🏫 Accessibility & Design Guidelines

* **Large Typography & High Contrast:** Uses readable fonts (`Fredoka` & `Nunito`) for young learners.
* **Visual & Audio Feedback:** Incorrect attempts trigger non-disruptive shake animations and life deductions without page reloads.
* **Self-Contained Client-Side Execution:** Operates entirely offline without needing a backend server.
